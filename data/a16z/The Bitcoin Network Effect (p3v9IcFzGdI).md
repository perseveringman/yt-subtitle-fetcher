## Description

It’s well understood that Bitcoin can be used to buy and sell things (and services), and the universe of people accepting the cryptocurrency as payment is expanding. But what else can we use the underlying protocol for? How can the same system that enables Bitcoin to flow and transactions to be recorded be expanded? This discussion from the a16z 2014 Academic Roundtable examines that question, and answers why Bitcoin the currency is not the end of the story when it comes to this technology.
